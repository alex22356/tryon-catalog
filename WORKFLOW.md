# Как пополнять каталог — пошагово

Ярлык на рабочем столе: **Tryon Catalog** (можешь переименовать как хочешь).
Открываешь — появляется меню из 5 пунктов. Ниже что делать в каком порядке.

---

## Разовая настройка (один раз, 5 минут)

1. **GitHub Pages.** В репозитории [tryon-catalog](https://github.com/alex22356/tryon-catalog):
   Settings → Pages → Source: **GitHub Actions**. (Workflow уже лежит в репозитории.)
2. **Приложение → сеть.** В `local.properties` поменяй строку на:
   ```
   CATALOG_URL=https://alex22356.github.io/tryon-catalog/catalog.json
   ```
   Пересобери приложение один раз. После этого **новые товары попадают на все телефоны
   без обновления приложения** — оно тянет каталог из сети и кэширует для офлайна.

Адрес публикации уже прописан в `publish_config.json`.

---

## Обычный цикл пополнения

### 1. Собрать ссылки — пункт **1**
Откроется инструкция. В своём браузере открываешь категорию SHEIN, **прокручиваешь**
(сколько прокрутил — столько товаров загрузилось), жмёшь закладку/вставляешь код в консоль →
все ссылки со страницы уходят в буфер.

### 2. Вставить ссылки — пункт **2**
Откроется `shein_links.txt`. `Ctrl+V`, `Ctrl+S`, закрыть.

### 3. Обновить каталог — пункт **3**
Само разберёт **только новые** ссылки: имя, фото вещи, категория
(спорные уточнит локальный ИИ). Покажет, что осталось примерить.

### 4. Примерка — пункт **4**
Откроется браузер: войди в Google, открой AI Studio, выбери модель
**Gemini 2.5 Flash Image** → вернись в окно и нажми Enter.
Дальше сам оденет модель в каждую вещь. Упрётся в дневной лимит — подождёт и продолжит.
Прервалось? Просто запусти пункт 4 снова — продолжит с того места.

### 5. Выложить всем — пункт **5**
Скопирует картинки в `public/`, перепишет ссылки на сетевые, сделает `git push`.
Через минуту GitHub Pages пересоберёт каталог → **у всех клиентов новые товары**.

---

## Что происходит внутри

```
ссылки (shein_links.txt)
   ↓  пункт 3
имя + фото + категория      → shein_products.json, garments/
   ↓  пункт 4
модель одета в вещь         → tryon_out/
   ↓  пункт 3 (или 5)
overlay 1:1 + миниатюра     → app assets + catalog.json
   ↓  пункт 5
public/ → git push → Pages  → catalog.json в сети
   ↓
телефоны клиентов тянут сами, кэшируют офлайн
```

---

## Когда одобрят фид Awin

Пункты 1–2 станут не нужны: вписываешь ссылку на датафид в `feeds.json`
(запись `SHEIN (Awin)`, `enabled: true`) — и товары, **цены**, наличие и партнёрские
ссылки подтягиваются сами, по расписанию, без твоего участия.

---

## Мелочи

- **Цены.** Сейчас у товаров `price: 0` и метка «ориентировочно» — SHEIN не отдаёт цену
  в открытых данных страницы. Появятся вместе с фидом Awin (или впиши вручную
  в `shein_products.json`).
- **Обувь.** В примерку не идёт — AI-модели надевают только одежду. Обувь остаётся
  наложением на манекен.
- **Всё идемпотентно.** Любой пункт можно запускать сколько угодно раз:
  обработается только новое.
