# Как пополнять каталог

Ярлык на рабочем столе **Tryon Catalog** → открывается меню из 5 пунктов.

---

## Настройка — один раз, 2 минуты

1. Запусти ярлык → пункт **1**. Откроется страница-инструкция.
2. Покажи панель закладок (`Ctrl+Shift+B`) и перетащи на неё зелёную кнопку
   **«Собрать товары SHEIN»**.

Всё. Больше настраивать нечего: GitHub Pages уже работает, приложение уже читает
каталог из сети.

---

## Обычный цикл — 3 действия

### 1. В браузере
Открой любую категорию SHEIN → **прокрути вниз** (сколько прокрутил, столько товаров
загрузилось) → нажми закладку **«Собрать товары SHEIN»**.
Появится «Собрано товаров: N» — данные (ссылка, название, фото) уже в буфере.

### 2. В окне каталога — пункт **2**
Заберёт всё из буфера, скачает фото вещей, определит категории
(спорные уточнит локальный ИИ), опубликует готовые примерки в приложение.
Повторы отсеиваются сами.

### 3. Примерка — пункт **3**
Откроется браузер: войди в Google → AI Studio → модель **Gemini 2.5 Flash Image** →
вернись в окно и нажми Enter. Дальше сам оденет модель в каждую вещь.
Упрётся в дневной лимит — подождёт и продолжит. Прервалось — просто запусти пункт 3
снова, продолжит с того места.

### 4. Выложить — пункт **4**
Публикация + `git push`. Через минуту каталог обновится **у всех клиентов**.

> Пункт **9** делает 2 → 3 → 4 подряд, если не хочешь нажимать по отдельности.

---

## Что происходит внутри

```
закладка в браузере  →  буфер обмена (ссылка + название + фото)
   ↓  пункт 2
фото вещей + категории       → shein_products.json, garments/
   ↓  пункт 3
модель одета в вещь          → tryon_out/
   ↓  пункт 2 или 4
overlay 1:1 + миниатюра      → приложение + products/
   ↓  пункт 4
git push → GitHub Actions → GitHub Pages
   ↓
телефоны клиентов забирают сами и кэшируют офлайн
```

Живой каталог: <https://alex22356.github.io/tryon-catalog/catalog.json>

---

## Важные оговорки

- **Ссылки обычные, не партнёрские.** Товары работают, но комиссия по ним не идёт.
  Партнёрские берутся через **Convert Link** в кабинете SHEIN — или придут пачкой,
  когда одобрят фид Awin.
- **Цены пока `0`** («ориентировочно»). SHEIN не отдаёт цену в открытых данных
  страницы; появятся с фидом Awin.
- **Обувь в примерку не идёт** — AI-модели надевают только одежду.
- **Чужие фото не публикуются.** `garments/` (фото SHEIN) закрыты в `.gitignore`;
  в сеть уходят только сгенерённые примерки.

---

## Когда одобрят фид Awin

Вписываешь ссылку на датафид в `feeds.json` (запись `SHEIN (Awin)`, `enabled: true`) —
и пункты 1–2 больше не нужны: товары, **цены**, наличие и партнёрские ссылки
подтягиваются сами по расписанию.
