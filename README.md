# Каталог товаров (репозиторий данных)

Содержимое этой папки — **готовый к копированию репозиторий**, который собирает и публикует
`catalog.json` для Android-приложения. Стоимость: **0 €** (GitHub Actions + Cloudflare Pages).

## Как запустить (10 минут)

1. **Создай репозиторий** на GitHub, например `tryon-catalog` (публичный — тогда Actions без лимита минут).
2. Скопируй в него содержимое этой папки:
   ```
   curated.json
   feeds.json
   scripts/build_catalog.py
   .github/workflows/update-catalog.yml
   ```
3. **Включи GitHub Pages**: Settings → Pages → Source: `GitHub Actions`.
   *(Либо подключи репозиторий к Cloudflare Pages — папка публикации `public`.)*
4. Запусти workflow вручную: вкладка **Actions** → *Update catalog* → **Run workflow**.
5. Получишь ссылку вида
   `https://<логин>.github.io/tryon-catalog/catalog.json`
6. Впиши её в `local.properties` Android-проекта:
   ```
   CATALOG_URL=https://<логин>.github.io/tryon-catalog/catalog.json
   ```
   Пересобери приложение — оно начнёт брать товары из сети.

Дальше каталог обновляется **сам, раз в сутки**.

## Как менять товары

- **Руками:** правь `curated.json` прямо на сайте GitHub (можно с телефона) → коммит →
  через минуту каталог пересобран.
- **Автоматически из фида:** добавь источник в `feeds.json` (см. комментарии внутри).
  Скрипт скачает фид, приведёт к общему формату и объединит с ручными товарами.

## Правила, зашитые в сборку

- `inStock: false` → товар не попадает в итоговый `catalog.json`.
- Товар из фида перекрывает ручной товар с тем же `id`.
- Каждому товару проставляется `checkedAt` (дата сборки) — приложение показывает
  «проверено ДД.ММ».
- Ручные товары помечаются `approx: true` → в приложении цена показывается как «≈».
