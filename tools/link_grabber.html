Сбор товаров SHEIN

Снимает товары со страницы, которую ты открыл сам: ссылку, название и фото. Никаких автоматических запросов — только то, что уже отрисовано у тебя на экране.

Настройка — один раз

  1. Покажи панель закладок: Ctrl+Shift+B
  2. Перетащи на неё зелёную кнопку ниже 👇
🛍️ Собрать товары SHEIN

Как пользоваться

  1. Открой любую категорию SHEIN (женская одежда, платья, обувь…).
  2. Прокрути вниз — сколько прокрутил, столько товаров и загрузилось. Обычно 20–60 за раз.
  3. Нажми закладку «Собрать товары SHEIN» → появится «Собрано товаров: N».
  4. Вернись в окно каталога и нажми 2. Дальше всё само.
Повторные товары отсеиваются автоматически — можно собирать одну и ту же категорию хоть каждый день, добавится только новое.

Если закладка не ставится

Открой на странице SHEIN консоль (F12 → Console), вставь это и нажми Enter:

Про партнёрские ссылки

Собранные ссылки — обычные, комиссия по ним не идёт. Товары в каталоге появятся и будут работать, но для заработка ссылку нужно заменить на партнёрскую (Convert Link в кабинете SHEIN) — либо дождаться фида Awin, где партнёрские ссылки приходят сразу для всех товаров.
